# ICP Persona

## 1. Ideal Customer Profile

The initial ideal customer for Daily Reset is an adult who experiences occasional mental overload, low energy or decision fatigue and wants a very simple tool that helps choose one manageable action.

The product is not designed for users seeking therapy, diagnosis or medical treatment.

## 2. Primary persona

### Name

Alex

### Age

22-35

### Situation

Alex studies or works in a cognitively demanding environment.

Daily responsibilities can include work, studies, household tasks and personal obligations.

Alex often knows that something should be done but sometimes struggles to decide what action is realistic in the current moment.

## 3. Main problems

Alex may experience:

- low energy,
- decision fatigue,
- mental overload,
- difficulty prioritizing small self-care actions,
- frustration caused by long task lists,
- inconsistent routines.

The problem is not a lack of available self-care advice.

The problem is choosing an appropriate action when energy, mood and available time are limited.

## 4. Current alternatives

Alex may currently:

- ignore the problem,
- scroll social media,
- create long to-do lists,
- use a habit tracker,
- use a wellness application,
- search online for self-care ideas,
- ask another person what to do,
- choose an activity randomly.

## 5. Why current alternatives may fail

Many existing tools require:

- creating routines,
- setting goals,
- managing multiple categories,
- configuring reminders,
- selecting from many options.

This can create additional cognitive effort.

Daily Reset should reduce this effort instead of adding another complex system.

## 6. User needs

Alex needs:

- a fast check-in,
- very few questions,
- recommendations matched to the current situation,
- activities that feel achievable,
- the ability to complete the flow quickly,
- simple history without a complex dashboard.

## 7. Expected user behaviour

A typical session should take approximately one or two minutes before the user starts the recommended action.

The user should not need to configure the application before using the core functionality.

## 8. Motivation to return

The user may return if:

- recommendations feel relevant,
- the interaction remains fast,
- previous check-ins are visible,
- the application helps reduce decision effort,
- simple statistics provide useful feedback over time.

## 9. Non-target users

The initial MVP is not primarily designed for:

- users looking for clinical mental health treatment,
- users who need advanced productivity management,
- teams or organizations,
- users looking for social networking,
- users looking for detailed fitness coaching,
- users expecting AI therapy.

## 10. Value proposition

For adults experiencing temporary overload or decision fatigue, Daily Reset provides a short context-based check-in that turns the user's current state into a small number of realistic micro-actions.

Unlike broad wellness and habit applications, Daily Reset focuses on helping the user decide what to do right now.
