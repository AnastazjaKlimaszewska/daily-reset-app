# Product Vision

## Product

Daily Reset is a simple web application that helps users choose a small activity based on their current energy level.

## Problem

People sometimes know that they should do something useful for themselves, but they have difficulty deciding what to choose, especially when they feel tired or overwhelmed.

Daily Reset reduces this decision effort by offering a small number of simple activities matched to the user's current energy.

## Target user

The target user is a person who wants a quick and simple self-care tool without creating an account or configuring a complex system.

## Product value

The main value of the application is simplicity.

The user only needs to:

1. select an energy level,
2. choose one suggested activity,
3. mark it as completed.

## MVP priorities

The highest priority is to provide a complete and understandable basic flow:

energy selection → activity recommendation → activity completion → history.

Additional features should not be added if they make the MVP unnecessarily complex.

## Future possibilities

Possible future development may include:

- more activity categories,
- customizable suggestions,
- user accounts,
- synchronization between devices,
- reminders,
- statistics.

These features are not part of the current MVP.
