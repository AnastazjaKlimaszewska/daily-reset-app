# User Flow

## Main flow

Start

↓

Open Daily Reset

↓

Select energy level

- Low
- Medium
- High

↓

View suggested activities

↓

Select one activity

↓

Activity marked as completed

↓

History entry created

↓

View recent history

## Alternative flow

If the user changes the energy level:

Selected activity is reset

↓

New activity suggestions are displayed

↓

The user can select a different activity
