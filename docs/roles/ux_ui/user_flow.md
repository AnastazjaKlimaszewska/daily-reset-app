# User Flow

## Main flow

Start

↓

Open Daily Reset

↓

View Dashboard

↓

Start Daily Check-in

↓

Select energy level

- Low
- Medium
- High

↓

Select mood

- Low
- Neutral
- Good

↓

Select mental load

- Low
- Medium
- High

↓

Select available time

- 5 minutes
- 10 minutes
- 20 minutes

↓

Submit check-in

↓

Application classifies current state

- Recovery
- Balanced
- Active

↓

Application displays exactly three recommendations

↓

User selects one recommendation

↓

User marks the selected action as completed

↓

Completed action is saved

↓

User can open History

↓

Previous check-in and completed action are displayed

↓

User can open Insights

↓

Application displays descriptive statistics

## Dashboard flow

Open Dashboard

↓

View:

- number of check-ins,
- completed actions,
- completion rate,
- latest state,
- latest completed action

↓

Start a new reset or navigate to another section

## History flow

Open History

↓

Load locally stored check-ins

↓

Load locally stored completed actions

↓

Match completed actions to check-ins

↓

Display newest records first

## Insights flow

Open Insights

↓

Load local records

↓

Calculate:

- total check-ins,
- total completed actions,
- completion rate,
- state distribution,
- most common state,
- action categories

↓

Display results

## Settings flow

Open Settings

↓

Read information about local data storage

↓

Optional action:

Clear local data

↓

Confirmation dialog

↓

If confirmed:

Delete all check-ins and completed actions

↓

Display success feedback

## Alternative flow — incomplete check-in

If the user has not selected all required check-in values:

The check-in cannot be submitted

↓

The user completes the missing input

↓

The full flow continues

## Alternative flow — recommendation selection

If the user selects a different recommendation before completing an action:

The new recommendation becomes active

↓

Only the selected recommendation is completed and stored
