# Implementation Workflow

## Plan workflow

Input:

A short description of one feature.

Output:

A complete plan file in `/docs/plans/PLAN_*.md`.

The plan should include:

- goal,
- scope,
- functional requirements,
- non-functional requirements,
- technical context,
- implementation steps,
- acceptance criteria,
- tests.

## Implement workflow

Input:

An approved feature plan.

Output:

- source code,
- tests or manual verification,
- updated documentation,
- updated `implemented_plans.md`,
- updated `implemented_features.md`.

## Implementation rule

The implementation should follow the approved plan and should not expand the feature scope without creating a new plan.
