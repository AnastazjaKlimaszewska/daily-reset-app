# ADR 002: Use Next.js and React for the frontend

## Status

Accepted

## Context

Daily Reset requires an interactive web interface where the content changes depending on the user's actions.

The project should also be simple to deploy and easy to extend with additional features.

## Decision

The application will be built using Next.js with React and TypeScript.

Tailwind CSS will be used for styling.

## Reasons

This stack was selected because:

- React supports interactive user interfaces,
- Next.js provides a clear project structure,
- TypeScript helps reduce programming errors,
- Tailwind CSS allows the interface to be styled without creating a large amount of custom CSS,
- Next.js applications can be deployed easily using services such as Vercel.

## Consequences

The application has a modern frontend structure and can be expanded later.

The project requires Node.js and npm during development, which adds some setup compared with a basic HTML page.
