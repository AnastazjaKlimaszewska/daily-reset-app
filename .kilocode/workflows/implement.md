# Implement Workflow

## Purpose

Implement one approved feature according to its Spec Driven Development plan.

## Input

An approved file from:

`/docs/plans/PLAN_*.md`

## Instructions

1. Read the selected plan completely before editing code.
2. Implement only the functionality described in the plan.
3. Do not expand the scope.
4. Follow the technology and architecture documented in `/docs`.
5. Keep the implementation simple and appropriate for the MVP.
6. Add or update tests required by the plan.
7. Verify the acceptance criteria.
8. Update `implemented_plans.md`.
9. Update `implemented_features.md`.
10. Update other documentation only if the implementation changes documented behaviour.
11. Do not add unrelated features.

## Validation

Before finishing:

1. Verify that the application builds.
2. Verify that the implemented feature works.
3. Verify that the result matches the acceptance criteria.
4. Verify that project documentation is consistent with the implementation.

## Output

Working source code, appropriate tests and updated project documentation.
